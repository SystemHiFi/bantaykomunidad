Community Alerts Protocol Guide
Severity Designations
  • Critical Red: Immediate threat to life or property (Floods, Fire).
  • Moderate Amber: Cautionary advisory, monitoring required (Weather updates, roadblocks).
Resolving Procedures

• Only authorized Desk Officers can set an alert to Resolved once the incident site is declared safe.

Brgy. Feed Protocol Guide
Feed Post Types
  • Pending Event: Activities scheduled for the future.
  • Ongoing Event: Activities currently in progress.
  • Completed Event: Concluded programs or announcements.
Mutual Aid Protocol Guide
Handling Aid Requests
  • Supply Offer: Resident is voluntarily offering excess goods (food, water).
  • Assistance Request: Resident requires urgent resources.
Verification Protocol Guide
Vetting Approvals
  • Ensure the ID image matches the resident's data form.
  • Confirm address proofs reflect the correct Purok mapping.
  • If rejecting an application, you must supply a rejection reason via the dropdown for transparency.
